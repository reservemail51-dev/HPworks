# SSGform 設定シート（コピーして貼り付ける用）

SSGform（https://ssgform.com）で、下の2つのフォームを作ります。
【仮】の部分は、決まったものに書きかえてから貼り付けてください。

---

## ① お問い合わせ用

フォーム名
```
お問い合わせ
```

通知先メールアドレス
```
【仮：メール】
```

送信後転送先URL
```
https://hpworks.hp-web.workers.dev/thanks.html
```

許可ホスト（https:// は付けない）
```
hpworks.hp-web.workers.dev
```

自動返信メール：**オン**（本文は `docs/自動返信メッセージ.md` の「1」）
返信先は、フォームの「メールアドレス」の項目（name="メールアドレス"）を指定します。

---

## ② 質問シート用

フォーム名
```
質問シート
```

通知先メールアドレス
```
【仮：メール】
```

送信後転送先URL
```
https://hpworks.hp-web.workers.dev/hearing-thanks.html
```

許可ホスト（https:// は付けない）
```
hpworks.hp-web.workers.dev
```

自動返信メール：オン（本文は `docs/自動返信メッセージ.md` の「2」）またはオフ

---

## 作ったあと

それぞれのフォームを保存すると、`https://ssgform.com/s/〇〇〇〇` のような「フォームURL」が表示されます。
**2つのURL（お問い合わせ用・質問シート用）を Claude に送ってください。**
`contact.html` と `hearing.html` の送信先（今は【仮：お問い合わせ用】【仮：質問シート用】）を差し替えます。

## テスト（サイトに反映されたあと）

- [ ] お問い合わせを1回送る → メールに通知が届く
- [ ] 自動返信メールが届く（迷惑メールフォルダも確認）
- [ ] 送信後に「お問い合わせ、ありがとうございます。」のページが出る
- [ ] 質問シートを1回送る → 通知が届き、「質問シートを、受け取りました。」のページが出る

送信でエラー（403 など）になるときは、許可ホストの打ち間違いを確認してください。
独自ドメインにしたら、送信後転送先URLと許可ホストも新しいドメインに変えます。
