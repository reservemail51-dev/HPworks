# 画像生成プロンプト（ChatGPT用）

サイトで使う画像を ChatGPT で作るためのプロンプト集です。ファイル名は `docs/制作指示書.md` の12章と同じにしてあります。

## 使い方

1. ChatGPT で**新しいチャットを1つ**開き、最初に下の「① 共通ルール」を送ります（「了解」と返ってくればOK）。
2. 同じチャットの中で、②以降のプロンプトを1つずつ送ります。**全部を同じチャットで作ると、絵柄がそろいやすくなります。**
3. 気に入った1枚をダウンロードし、ファイル名を一覧のとおりに付けて保存します。
4. Claude Code に「`public/images` に画像を入れたので、WebPに変換して差し替えて」と頼みます。

### うまくいかないときの一言（同じチャットで送る）

- 細かすぎる・AIっぽい →「もっと線と色を減らして、余白を多く。描き込みは半分くらいに」
- 背景が透過になっていない →「背景を透過（透明）のPNGで出し直して」
- 文字が入ってしまった →「画像の中の文字・数字・ロゴをすべて消して」
- 人物の雰囲気がバラバラ →「①の人物ルールに合わせて、前に作った画像と同じ絵柄で」
- 色が派手 →「彩度を下げて、①の色だけで」

> 前回（愛媛東予Works）の画像は、細かく描き込まれた水彩の風景でした。きれいですが、こういう「描き込みの多い水彩風景」はAIで作った画像だと気づかれやすい絵柄です。今回は **線が少なく、色数が少なく、余白の多い** イラストにして、手で描いたような素朴さを出します。

## ① 共通ルール（最初に1回だけ送る）

```
これから、ちいさなお店向けのホームページ制作サービスのサイトに使うイラストを、何枚か続けてお願いします。すべて次のルールで、同じ絵柄にそろえてください。

【絵柄】
・ペンで描いた線画に、色鉛筆でざっくり色をのせたような、素朴な手描きイラスト
・線は焦げ茶色（#3A332C くらい）で、太さが少し不ぞろい。定規で引いたようなまっすぐな線にしない
・色はところどころ塗り残しがあり、線から少しはみ出してもよい
・描き込みは少なめ。小物や背景を描きすぎず、余白を多くとる
・紙に描いたような、ごく薄いざらっとした質感

【色】（この色だけを使う。彩度は低め）
・れんが色 #B44E33
・からし色 / 付箋のきいろ #F5D565
・くすみ紺 #3B5A7A
・ミント #A8D5C2
・肌色、生成り、薄いグレー

【人物】
・顔はシンプル（目は点、口は短い線、鼻は描かないか小さく）
・頭身は5〜6頭身くらい。アニメ調・リアル調にしない
・表情はおだやか。大げさなポーズにしない

【やらないこと】
・文字、数字、ロゴ、看板の文字、画面の中の文字（スマホやパソコンの画面は、四角や線でぼかして表現）
・グラデーション、光沢、3D、強い影、光のエフェクト、キラキラ
・紫や青のネオンカラー、未来的・デジタル的なモチーフ
・ジブリ風・特定の作家やアニメの絵柄のまね
・写真のようなリアルな表現、細かく描き込んだ風景

【出力】
・特に指定がない限り、背景は透過（透明）のPNG
・1枚ずつ出してください

了解したら「了解」とだけ返してください。
```

## ⑦ つくっている人 `profile-illust.png`（800×800・透過）

**自分の写真をChatGPTにアップロードしてから**送ってください。顔を出したくない場合は、下の「顔を出さない版」を使います。

### 似顔絵版
```
添付した写真の人物を、①のルールの絵柄で、似顔絵イラストにしてください。正方形。胸から上、少しななめを向いて、おだやかに笑っている感じで。手にはノートパソコンかスマホ。似せすぎず、雰囲気がわかるくらいでOKです。服の色はくすみ紺。背景は透過。
```

### 顔を出さない版
```
正方形のイラストをお願いします。机に向かってノートパソコンで作業している人を、斜め後ろから描いた絵（顔は見えない）。机の上にマグカップと、付箋のきいろの付箋が何枚か。服の色はくすみ紺。背景は透過。
```

## ⑨ Instagramの発信枠 `insta-1.png`〜`insta-3.png`（各1080×1080）

サイトのトップ下部に「Instagramでも発信しています」として並べる3枚です。**実際の投稿ができたら、その画像に差し替えるのがいちばん**です。それまでのつなぎとして作ります。背景あり（生成り色 #FAF7F0）。

```
正方形のイラストを3枚、同じ絵柄でお願いします。背景は透過ではなく、生成り色（#FAF7F0）でぬってください。

1枚目：机の上に、方眼ノートと付箋と色鉛筆が散らばっている。ノートには四角と線だけのホームページのラフ（文字なし）。
2枚目：スマホが1台、ななめに置かれていて、画面にはお店の写真と線だけのホームページ。そばにマグカップ。
3枚目：パン屋の店先の小さな絵と、その横にスマホ。ひさしはれんが色。

どれも文字は入れないでください。
```

## ⑩ シェア画像の背景 `ogp-bg.jpg`（1200×630）

URLをLINEやDMで送ったときに出る画像の背景です。文字はあとでHTMLで重ねるので、**真ん中から左を大きくあけて**ください。

```
横長（1200×630の比率、約1.9:1）の画像をお願いします。背景は透過ではなく、生成り色（#FAF7F0）。

右側だけに、②と同じ絵柄で、小さなお店の店先と、スマホを持った店主の女性を小さめに描いてください。左側の3分の2は何も描かずにあけておいてください（あとで文字を入れます）。紙のようなごく薄いざらっとした質感。文字は入れないでください。
```

## ⑪ アイコン `favicon.png`（512×512）

ブラウザのタブやスマホのホーム画面に出る小さなアイコンです。小さく表示されるので、形はできるだけ単純にします。

```
正方形のアイコンをお願いします（512×512）。背景はれんが色（#B44E33）の角の丸い正方形。その中央に、生成り色の線で、ひさしのついた小さなお店の形を、ごくシンプルに（線5〜6本くらい）。文字は入れません。小さく表示しても形がわかるように、細かい描き込みはしないでください。
```
