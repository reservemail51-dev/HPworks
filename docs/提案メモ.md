# 提案メモ（SNS集客版のサイトについて）

`docs/制作指示書.md` を使う前に、決めておくとよいことと、あると強いものをまとめました。上から優先度の高い順です。

---

## 1. 制作を始める前に決めたいこと

### 屋号
「愛媛東予Works」は地域名が入っているので、全国向けには別の名前がおすすめです。SNSは「誰がやっているか」で選ばれやすいので、**ハンドルネームを入れた名前**にすると覚えてもらいやすくなります。

- 例：「〇〇のホームページ屋さん」「ホームページ係の〇〇」「〇〇 web製作室」（〇〇はハンドルネーム）
- ひらがな・カタカナが入っていると、インスタの検索で見つけてもらいやすく、口頭でも伝わります。
- 決まったら、同じ名前でInstagramのID・LINE公式アカウント・ドメインが空いているかを先に確認してください。

### LINE公式アカウントを分けるか
LINE公式アカウントの表示名は1つなので、今のアカウント（愛媛東予Works）を使うと、全国の人に「愛媛東予Works」と表示されます。**新しくもう1つ作る（無料）のがおすすめ**です。愛媛東予Worksのサイトはそのまま残して、地域の検索から来る人の窓口にしておけます。

### 独自ドメイン
お客さんには「ドメインはお店の名義で」とおすすめしているので、自分のサイトも独自ドメイン（例：`〇〇.com`／`〇〇.jp`）にしておくと説得力が上がります。Cloudflare で年1,500〜2,000円ほど（.comの場合）。`workers.dev` のままでも動きます。

## 2. 料金・お支払いまわり（料金そのものは前回と同じにしてあります）

### 5,000円の案件の「半分ずつ払い」
5,000円を2,500円ずつ2回振り込んでもらうのは、お客さんにとっても手間です。たとえば
**「1万円未満は、公開前の確認でOKをもらってから一括払い」**
にすると、手間が減るうえに「先にお金を払わなくていい」という安心感にもなります。決めたら指示書の6章・7章・8章を直してください。

### 振込手数料
全国のお客さんだと銀行がバラバラなので、振込手数料をどちらが持つかをFAQに一言入れておくと親切です。今後、PayPay やカード払い（Square・Stripe の支払いリンク）を足すのもありです。

### 無料デモの範囲と数
全国から相談が来ると、デモづくりの時間が足りなくなるかもしれません。
- デモの範囲を「トップページの最初の1〜2画面分」とはっきり書く
- 「デモは質問シートに答えていただいた方におつくりしています」とする
- 忙しいときは「今月のデモ受付は終了しました」と出せるようにしておく

あたりを決めておくと安心です。

## 3. はじめの実績づくり

- **モニター募集**：最初の3件だけ「実績として掲載OK・感想を書いていただける方」を条件に、特別価格（例：制作費0円〜、ドメイン代のみ）で受ける。これで本物の「お客様の声」が手に入り、SNSの投稿ネタにもなります。
- **サンプルの追加**：前回の6件は飲食・美容室・お菓子・パンです。SNSで多い **ネイル・まつげサロン／ヨガ・ピアノなどの教室／ハンドメイド作家** のサンプルを2〜3件足すと、「うちの業種でもできそう」と思ってもらいやすくなります。

## 4. SNSの発信について

### プロフィール
- 名前欄：屋号＋「個人店のホームページ制作」
- 自己紹介欄（例）：「インスタだけのお店に、ちょうどいいホームページを。／1ページ5,000円〜・無料デモあり／全国オンライン対応」
- リンク：`links.html`（指示書の3章）を貼る。

### 投稿のネタ（続けやすいもの）
1. **「架空のお店のホームページをつくってみた」**：サンプルサイトをスマホで画面録画して、スクロールするだけのリール。既存の6件ですぐ6本つくれます。
2. **ビフォー・アフター**：「インスタのハイライトに詰め込んだ情報」→「ホームページにまとめるとこうなる」の比較（架空のお店で）。
3. **店主さん向けの小ネタ**：「DMで同じ質問をされなくなる方法」「Googleマップの営業時間、合ってますか？」など。売り込みではなく役に立つ話。
4. **料金を正直に**：「5,000円で何ができる？」「月々0円でも大丈夫な理由」。
5. **制作の裏側**：付箋・ノート・ラフの写真。つくっている人の手が見えると、安心感につながります。

Threads は文章の投稿が読まれやすく、個人事業主どうしのつながりもできやすいので、3と4のネタと相性がいいです。

### 気をつけたいこと
- 知らないお店にいきなり営業のDMを送るのは、迷惑に思われやすく、アカウントが制限される原因にもなります。
- 実在のお店の写真やロゴを、許可なくデモや投稿に使わないでください（デモをつくるのは、相談をもらってからに）。

## 5. 計測

- フォームと質問シートに「このサイトを知ったきっかけ」を入れてあります（指示書10章）。
- Cloudflare Web Analytics を入れておくと、どのページがよく見られているか、どこから来たかがわかります。プロフィールのリンクを `links.html?from=instagram`、Threads は `?from=threads` のように分けておくと、どのSNSから来たかがわかります。

## 6. 副業として続けるために（念のため）

- 本業の会社の就業規則で、副業が認められているかを確認しておいてください。
- 収入が出てきたら、確定申告や住民税の申告が必要になることがあります。開業届を出すかどうかも含めて、一度、税務署か税理士さんに確認しておくと安心です。
- 返信時間（7時〜20時）を最初から書いておくのは、副業で無理なく続けるためにも良い決め方だと思います。
