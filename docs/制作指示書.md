# 依頼：SNSで集客する「ちいさなお店のホームページ制作」の自社サイトを作ってください

あなたはWebデザイナー兼コピーライターです。以下の方針で、私（個人のホームページ制作者）の自社サイトを制作してください。
わからない点・未確定の情報は【仮】と書いたプレースホルダーのまま進め、最後に「未確定項目リスト」として一覧で報告してください。

**参考にする前回のサイト**：https://github.com/reservemail51-dev/ehime-toyoworks（愛媛東予Works）
- 料金・ご依頼の流れ・FAQ・フォーム・実績の仕組み・サンプルサイトは、このリポジトリの内容を土台にしてください（必要ならクローンして中身を読んでください）。
- **デザイン（色・フォント・イラスト）と地域向けの文言は流用しないでください。** 今回は地域を限定せず、SNS経由で全国の個人店に向けたサイトです。

## 1. 目的・ターゲット

- **誰に**：全国の、個人で営んでいるお店・教室・サロンの店主さん。
  - 例：カフェ・パン屋・小さな飲食店、個人の美容室・ネイル・まつげ・エステ、整体・鍼灸、ピアノ・ヨガ・書道などの教室、ハンドメイド作家、キッチンカー、小さな工房・農家の直売。
  - 「Instagramはがんばっているけど、ホームページはない」「リンクまとめページで済ませている」「DMで同じ質問に毎回答えている」「制作会社は高そう」「ネットで知らない人に頼むのは少し不安」という人。
  - 30〜60代の店主が、**InstagramやThreadsのプロフィールのリンクからスマホで開いて**読むことを前提にする。パソコンで見る人は少数。
- **サイトのゴール**：気軽に「LINEで相談」「InstagramのDMで相談」または「無料デモを頼む（かんたん質問シート）」をしてもらうこと。売り込み感は出さない。
- **SNSから来た人の気持ち**：投稿を見て「ちょっと気になる」くらいで開いている。最初の画面で「何をしてくれる人か／だいたいいくらか／どうやって相談するか」がわかり、「この人なら頼めそう」と感じてもらうことを最優先にする。
- **遠くの知らない人に頼む不安**をやわらげることを、サイト全体のテーマにする（デモを先に見られる・お支払いは半分ずつ・つくったものはお店のもの・やりとりの雰囲気が見える）。

## 2. 技術ルール

- 静的な HTML / CSS / JavaScript のみ。ビルドツール・フレームワークは使わない。日本語サイト。
- 公開先は Cloudflare（Workers の静的アセット。GitHub連携）。**公開するのは `public/` フォルダだけ**。ページ・CSS・JS・画像・データはすべて `public/` の中に置き、`docs/`・`tools/`・説明書はリポジトリ直下に置く。`wrangler.jsonc` もリポジトリ直下に作る（前回のリポジトリを参考に）。
- 共通CSSは `public/css/style.css`、共通JSは `public/js/main.js`。色・フォントは `:root` のトークンを使う（直書きしない）。ヘッダー・フッターは全ページで同じ内容をコピーで持つ（変更時は全ページ一括で直す）。
- `public/_headers` でセキュリティ用ヘッダーとキャッシュを設定（前回と同じ考え方）。
- スマホファースト。**幅360pxで横スクロールが出ないこと**。本文16px以上、行間1.9前後、ボタンの高さ48px以上。
- **InstagramやLINEのアプリ内ブラウザで開かれる前提**で作る：
  - 画面の高さに `100vh` を使わない（アプリ内ブラウザで下が切れるため。必要なら `100svh`）。
  - 重いアニメーション・動画の自動再生・大きな画像を避け、最初の画面がすぐ表示されるようにする。
  - LINE・Instagram・メールへのリンクは、アプリ内ブラウザから押しても開けるふつうの `<a href>` にする。
- 画像は `public/images/` 配下、WebP、`loading="lazy"`（ファーストビューを除く）、必ず `width`/`height` と日本語の `alt` を付ける。
- 未用意の画像は、ファイル名を決めたうえで「ダミー枠（背景色＋ファイル名を小さく表示）」にしておく（ファイル名は **12章** の一覧に合わせる）。
- 価格には `<!-- PRICE -->` コメントを付けて、あとで一括で変えやすくする。
- 全ページの `</body>` 直前に Cloudflare Web Analytics のスクリプトを入れる場所をコメントで用意する（トークンは【仮】）。
- `CLAUDE.md` を作成し、上記ルール・デザインの禁止事項・実績の追加手順を書いておく。`README.md` には使い方と実績の追加手順（Claude Codeへの頼み方の例文つき）を書く。

## 3. ページ構成

| ファイル | ページ | 内容 |
|---|---|---|
| `index.html` | トップ | 下記「トップの構成」。**SNSから来た人はほぼここしか見ない**ので、トップだけで判断できる内容にする |
| `service.html` | サービス・料金 | できること、制作の料金、公開後の3プラン、オプション、かかるお金のまとめ |
| `works.html` | 制作実績 | 実績一覧（絞り込み付き） |
| `work.html` | 実績の詳細 | `work.html?id=スラッグ` でデータから表示 |
| `flow.html` | ご依頼の流れ | 相談〜公開〜公開後まで。「ここまで無料」の区切りをはっきり |
| `faq.html` | よくある質問 | カテゴリ別アコーディオン（吹き出しの会話形式） |
| `contact.html` | お問い合わせ | LINE・Instagram DM・フォーム・メール |
| `thanks.html` | 送信完了 | フォーム送信後の表示＋「質問シートに答える」ボタン |
| `hearing.html` | 無料デモの申し込み（かんたん質問シート） | 5分で答えられる質問シート。noindex |
| `hearing-thanks.html` | 質問シート送信完了 | noindex |
| `links.html` | SNSプロフィール用のリンクページ | Instagram等のプロフィール欄に貼る1枚。大きなボタンが縦に並ぶだけ。noindex（下記） |
| `404.html` | ページが見つからない | やさしい文言＋トップへのリンク。どの階層でも表示できるよう `/` から始まるパスを使う |

- プライバシーポリシーのページは置かない。代わりに、フォームと質問シートの送信ボタンの上に「いただいた内容は、ご相談へのお返事とホームページづくりのためだけに使い、ほかの目的には使いません。」の一文を置く。
- 自己紹介は独立したページにせず、トップの「つくっている人」セクションにまとめる。

### トップの構成（上から順に）

1. **ファーストビュー**（幅360px・高さ640pxの画面で、ボタンまで見えること）
   - 小さな前置き：「全国どこからでも、オンラインで」
   - キャッチコピー（1つ採用し、残りはHTMLコメントで残す）
     - 「インスタの次は、ホームページ。」
     - 「ちいさなお店に、ちょうどいいホームページを。」
     - 「DMで毎回聞かれること、ホームページにまとめませんか。」
   - サブ：「個人で営むお店や教室のホームページ・LPを、オンラインでつくっています。1ページ5,000円〜（税込）。つくる前に、無料でデモをお見せします。」
   - ボタン2つ：「LINEで気軽に相談」「無料デモを頼んでみる（→ hearing.html）」。その下に小さく「InstagramのDMでもOKです」のテキストリンク。
   - ボタンの下に、カードにせず**1行の文字で**：「相談・デモは無料／全国オンライン対応／月々0円でもOK」
   - 手描き風イラスト `hero-illust`。スマホでは文字の下に小さめに置き、ボタンを押し下げないこと。
2. **こんなこと、ありませんか？**：店主さんの吹き出し（口ぐせのような言葉）を4〜5個、少しずつ位置と角度をずらして配置。イラスト `worry-illust`。
   - 「営業時間、またDMで聞かれた…」
   - 「メニューも料金も、ハイライトに詰め込んでる」
   - 「リンクまとめのページだけで、なんとかしてる」
   - 「ホームページって、何十万円もかかるんでしょ？」
   - 「ネットで知らない人に頼むのは、ちょっと不安」
   - 最後に「わたし」の吹き出しで受ける：「どれも、よく聞くお話です。むずかしい話は抜きにして、ひとつずつ一緒に整えていきましょう。」
3. **インスタとホームページ、役割がちがいます**：手描き風の2列の図（カードにしない。ノートに書いたメモのような見た目）。
   - インスタ：お店の雰囲気・新しいお知らせ・常連さんとのやりとり
   - ホームページ：変わらない基本情報（メニュー・料金・営業時間・場所・予約方法）、検索で見つけてもらう
   - 結び：「インスタはそのまま。プロフィールのリンク先を、ホームページにするだけです。」
4. **できること**：ホームページ制作／LP（1枚で完結するページ）制作／リニューアル。アイコン付き3カラムカードは使わず、イラスト＋短い説明のジグザグ配置。
5. **制作実績ピックアップ**：`pickup: true` のもの最大3件＋「実績をもっと見る」。スマホ画面の画像を中心に。架空のサンプルにはその旨を表示。実績が0件のときはセクションごと自動で隠す。
6. **料金のめやす**：「ホームページ制作 5,000円〜（税込）」と、公開後の3プランを「名前・月額・ひとこと」だけで。細かい内訳は出さず「くわしくはサービス・料金へ」。
7. **はじめてでも頼みやすいように（約束ごと3つ）**：番号は手書き風。同じ形のカードにしない（文章量・配置に差をつける）。
   - **つくる前に「デモ」を見てから決められる**：お店に合わせたトップページのデモを先につくって、スマホで見てもらう。イメージと違えば、そこでお断りいただいて大丈夫（費用はかからない）。
   - **お支払いは、着手時と公開時の半分ずつ**：全額前払いではない。内容・金額・スケジュールは書面でお渡しする。
   - **つくったサイトは、あなたのもの**：ドメイン（＝ホームページの住所）やデータはお店の名義。最低契約期間なし、いつでもお引っ越しできる。
8. **やりとりのイメージ**：LINE風の会話（HTMLとCSSで組む。画像にしない）を短く。見出しの近くに「※やりとりのイメージです」と明記する。お客様の実際の発言として見せない。
   - 例：店主「インスタしかないんですが、相談していいですか？」→ わたし「もちろんです！まずはお店のことを少し教えてください。質問シート（5分ほど）をお送りしますね」→ 店主「答えました」→ わたし「ありがとうございます。デモができたので、スマホで見てみてください（URL）」
9. **ご依頼の流れ（かんたん版）**：5ステップを手書き風の番号で。「ここまで無料」の位置に付箋風のメモ。「流れをくわしく見る」。
10. **つくっている人**：似顔絵イラスト `profile-illust`＋ハンドルネーム＋2〜3行の自己紹介【仮】＋Instagramへのリンク。「わたしがひとりで、最初から最後まで担当します。」を入れる。
11. **よくある質問（抜粋3問）**：「どうしてこんなに安いの？」「遠くても頼める？」「月々いくらかかる？」＋「ほかの質問も見る」。
12. **最後のお誘い**：「まずは、DMひとつからどうぞ。」＋「うちの場合はいくら？」「そもそも必要？」からでも大丈夫、という一文＋LINE／Instagram DM／フォームのボタン＋返信時間の案内。

- スマホでは画面下に小さな固定ボタン（「LINEで相談」）。PCでは非表示でOK。ファーストビューのボタンが見えている間は出さない。

### links.html（SNSプロフィール用のリンクページ）

- Instagram・Threads等のプロフィール欄にはこのページのURLを貼る想定。リンクまとめサービスの代わり。
- 上から：屋号・アイコン・ひとこと → 大きなボタンを縦に5つ（「無料デモを頼む」「LINEで相談」「料金を見る」「制作実績を見る」「よくある質問」）→ 小さく「サイトのトップへ」。
- 画面1枚に収める。noindex。

## 4. デザイン方針：「AIっぽくない・親近感のある」デザイン

コンセプト：**「店主さんのノートに書いた、ホームページの相談メモ」**。方眼ノート・付箋・鉛筆の線。つくっている人の手の跡が見える、ちょっと手づくり感のある画面。デザイン性で驚かせるより、「話しやすそう」「ちゃんとしてそう」と思ってもらうことを優先する。

### カラー（`:root` にデザイントークンとして定義）

- 背景：生成り `#FAF7F0`（白一色にしない）
- 文字：墨 `#2E2B27`（真っ黒にしない）
- メインアクセント：れんが色 `#B44E33`（ボタン。白文字とのコントラスト比 5.1 で確保）
- マーカー：付箋きいろ `#F5D565`（大事な言葉のマーカー・付箋）
- サブ：くすみ紺 `#3B5A7A`（リンク・見出しの小飾り）
- 差し色：ミント `#A8D5C2`（ごく少量）
- LINEボタンだけは LINE の緑 `#06C755` を使ってよい（ほかの場所で緑を使わない）

### フォント（Google Fonts）

- 見出し：M PLUS Rounded 1c（700/800）
- 本文：BIZ UDPGothic（400/700）… 年配の方にも読みやすいUDフォント
- 手書きアクセント：Yomogi … 吹き出し・付箋・注釈など **短い言葉だけ** に使う（長い文章には使わない）

### 取り入れる表現

- 背景のところどころに、ごく薄い方眼（ノートのマス目）。全面ではなくセクション単位で。
- 付箋風のメモ（少し傾ける。-3〜3度。すべて同じ角度にしない）を「ここまで無料」「いちばん多いご相談」など要所だけに。
- 手描き風の下線・丸囲み・矢印（SVGパスで線を少しゆらす）を見出しや大事な言葉に“ところどころ”。
- 写真やスマホ画面の画像は、マスキングテープで留めたように少し傾けて配置。
- 「こんなことありませんか？」「FAQ」は**吹き出しの会話形式**（店主さん ⇔ わたし）。
- 左右非対称のレイアウト、要素の大きさにメリハリ。余白は“ゆったり”だが間延びさせない。
- アニメーションは控えめ（付箋がふわっと出る程度、全要素にはかけない。`prefers-reduced-motion` に対応）。

### 禁止事項（AIっぽさの原因になるもの）

見た目：
- 紫〜青のグラデーション、ネオン、ガラス風（グラスモーフィズム）、光る球体、ぼかした色の玉（ブロブ）、宇宙・回路・ロボット・キラキラ（✨）系のモチーフ
- 「アイコン＋見出し＋説明」の同じ形のカードを3つ・6つと並べるだけのレイアウト、ベントーグリッド
- 「実績◯件・満足度◯%」などの数字カウンター
- 絵文字をアイコン代わりに使うこと
- 全部中央揃え・完全左右対称のページ、全セクションが同じ「見出し→リード→カード」の型
- 角丸と影の強いカードの多用、全要素のフェードインアニメーション
- 英語の飾り見出し（“Our Service”“STEP 01” など）
- 実在しない「お客様の声」や数字を作ること

文章：
- 「想いをカタチに」「伴走します」「寄り添います」「次のステージへ」「最適なソリューション」「ワンストップで」「ブランディングを加速」「〜を、もっと身近に。」のような決まり文句
- 体言止め・「——」（ダッシュ）・「！」の多用、すべての見出しが同じリズムになること

## 5. 文章のトーン

- 一人称は「わたし」。です・ます調だけど、DMで話しかけるようにやわらかく。
- 専門用語は使わないか、使うなら一言で言い換える（例：「ドメイン（＝ホームページの住所）」「LP（1枚で完結するページ）」「サーバー（＝ホームページを置いておく場所）」）。
- 具体的な場面を入れる（例：「営業時間をDMで毎回聞かれる」「ハイライトにメニューを詰め込んでいる」「予約の受付がDMだけで大変」）。地名は入れない。
- 押し売りしない。「まずは話だけ」「相談だけでも大丈夫です」「デモを見て断ってもOK」を随所に。
- 料金は隠さない。「あとから『聞いてない』がないように」を大事にする。

## 6. 料金・プラン（前回の愛媛東予Worksと同じ。段階的に見せる）

**見せ方の方針**：トップでは「制作 5,000円〜」と公開後のプラン名・月額だけ。サービス・料金ページで含まれる内容を一覧で。ドメイン名義・譲渡・解約・著作権などの細かいことは **FAQに畳んでおく**（聞きたい人だけが開く）。
価格はすべて税込表示。HTML内に `<!-- PRICE -->` コメントを付ける。

### 制作の料金（プランは1つだけ）

**ホームページ制作　5,000円〜（税込）**
- 1ページのホームページ・LPを基本に、ページや機能は必要なぶんだけ足していく。お話をうかがってから正式なお見積り。「この予算の中でできること」からの相談も歓迎。
- こんな方に：まずはお店の基本情報をまとめたい／新メニューやイベント、生徒募集の告知ページがほしい／少しずつ育てていきたい
- 基本の内容（縦に長い1ページ）：お店のひとこと紹介と写真／メニュー・料金／営業時間・定休日／アクセス（地図・駐車場）／LINE・電話・予約へのボタン
- 含まれるもの：1ページ分のデザイン・制作／お手持ちの写真をそのまま使える（スマホで撮ったものでOK）／いただいた文章を読みやすく整えて掲載／地図の表示とLINE・電話・予約へのボタン
- 必要に応じて足せるもの（内容に合わせてお見積り）：ページの追加（1ページ 3,000円〜）／お問い合わせフォーム／「お知らせ」欄／お店の名前や地域名で検索したときに出やすくする基本設定／お使いの予約サービスとの連携／採用（求人）ページと応募フォーム／お話を聞いての文章の書きおこし

## 7. 相談〜公開の流れ（flow.html）

1. **お問い合わせ（無料）**：LINE・InstagramのDM・フォーム・メール、どれでもOK。「まだ決めていない」「相場だけ知りたい」も歓迎。
2. **お話を聞かせてください（無料）**：基本は文字のやりとり。希望があればオンライン（Zoom／Google Meet／LINE通話）で30分ほど。5分で答えられる「かんたん質問シート」をお送りする（先に答えてもらってもOK）。
3. **無料デモ・お見積り（無料）**：お店に合わせたトップページのデモをつくって、スマホで見てもらう。あわせて正式なお見積り。イメージと違えば、ここでお断りいただいてOK。**ここまで費用は一切かからない**。
4. **ご契約**：内容・金額・スケジュールを書面でお渡し。お支払い：着手時に半分、公開時に残り半分（銀行振込）。
5. **制作・確認**：確認用のURLをお送りし、スマホで見ながら「ここの文字を大きく」「この写真に変えたい」などをLINEやDMで伝えてもらう。
6. **公開**：ドメインの設定と表示のチェックをして公開。かんたんな使い方もご説明。InstagramのプロフィールのリンクをホームページのURLに変えるところまでお手伝いする。
7. **公開したあと**：セルフ／おまかせ／まるごとから選べる。あとから切りかえも可。

あわせて載せるもの：
- 「あると話が早いもの（なくても大丈夫）」：お店の名前・場所・営業時間・定休日／今お使いのInstagramやGoogleマップのお店情報／お店や商品の写真（スマホで撮ったものでOK・Instagramの投稿写真を使ってもOK）／「こんな感じがいい」と思うホームページ（あれば）／だいたいのご予算と公開したい時期
- 公開までの目安：1ページ（LPなど）2〜3週間ほど／5ページ前後 1〜1.5か月ほど／10ページ前後 1.5〜2か月ほど（写真や文章がそろうタイミングで前後）
- 連絡について（contact.html にも）：ご相談から公開までオンラインで完結。お電話でのご相談は受け付けていない。LINEやDMなら営業中でも気軽に送れる。返信は原則24時間以内、返信時間帯：基本7時頃〜20時頃／平日・土日問わず。

## 13. 進め方と完成チェック

1. まず **トップページだけ** を作ってプレビューを見せる（デザインの方向性を確認するため）。幅360pxのスクリーンショットも見せる。
2. OKが出たら残りのページを作成。
3. 完成時に以下を確認して報告：
   - 幅360px／768px／1280pxで崩れない（横スクロールが出ない）
   - 幅360px・高さ640pxで、トップのボタンが最初の画面に見えている
   - 全リンクが切れていない、フォームが送信先に向いている
   - 禁止事項（4章）に当てはまる表現・文言がない
   - 料金が6章と一致している（`grep -rn "PRICE" public` で確認）
   - 移植したサンプルに「愛媛東予Works」の表記・旧URLが残っていない
   - 未確定項目（【仮】）の一覧（`grep -rn "【" public`）
   - 実績の追加手順が README に書かれている
