# 自動返信メッセージの文面

問い合わせがあったときに、自動で返すメッセージの文面です。【仮】の部分は、決まったものに書きかえてから使ってください。

---

## 1. お問い合わせフォームの自動返信メール（SSGform）

SSGform の無料プランでも「自動返信メール」が使えます。設定のしかたは `docs/SSGform設定シート.md`。
※LINEの表示名・InstagramのIDだけを書いた方にはメールが届かないので、こちらから LINE・DM で連絡します。

件名：
```
【【仮：屋号】】お問い合わせありがとうございます
```

本文：
```
この度はお問い合わせいただき、ありがとうございます。
【仮：屋号】の【仮：ハンドルネーム】です。

ご相談の内容を受け取りました。
返信は原則24時間以内にさせて頂きます。
（返信時間帯：基本7時頃〜20時頃／平日・土日問わず）

お時間があれば、下の「かんたん質問シート」にもお答えください。
選ぶだけの質問がほとんどで、5分ほどで終わります。
先に答えていただくと、無料デモのご用意が早くなります。

▼かんたん質問シート
https://hpworks.hp-web.workers.dev/hearing.html

※このメールは自動で送信しています。
※お心当たりのない場合は、お手数ですがこのメールを削除してください。

【仮：屋号】
メール：【仮：メール】
LINE：https://lin.ee/【仮：LINE】
Instagram：https://www.instagram.com/【仮：Instagram】/
```

## 2. 質問シートの自動返信メール（任意）

件名：
```
【【仮：屋号】】質問シートを受け取りました
```

本文：
```
質問シートにお答えいただき、ありがとうございます。
【仮：屋号】の【仮：ハンドルネーム】です。

いただいた内容をもとに、無料デモとお見積りのご用意をはじめます。
できあがったら、ご連絡先あてにURLをお送りします。
デモを見てからお断りいただいても大丈夫です。

※このメールは自動で送信しています。

【仮：屋号】
LINE：https://lin.ee/【仮：LINE】
```

## 3. LINE公式アカウントの「あいさつメッセージ」

友だち追加されたときに自動で送られるメッセージです（無料・通数にも数えられません）。
LINE Official Account Manager →「あいさつメッセージ」に貼り付けます。

```
{Nickname}さん、友だち追加ありがとうございます！
【仮：屋号】の【仮：ハンドルネーム】です。

ホームページのご相談は、このトークにそのままメッセージを送ってください。
「まだ決めていない」「相場だけ知りたい」でも大丈夫です。

無料デモをご希望の方は、先に「かんたん質問シート」にお答えください（5分ほどです）。
https://hpworks.hp-web.workers.dev/hearing.html

返信は原則24時間以内にさせて頂きます。
返信時間帯：基本7時頃〜20時頃／平日・土日問わず
```

「応答メッセージ」で「質問シート」「料金」というキーワードに、それぞれ質問シートのURL・料金ページのURL（https://hpworks.hp-web.workers.dev/service.html）を返す設定をしておくと便利です。

## 4. Instagram の DM（よくある質問・自動返信）

Instagram のプロアカウントでは、DM画面に「よくある質問」のボタンを出したり、メッセージに自動で返信したりできます（設定 →「ビジネスツールとコントロール」など。名前はアプリの版で変わります）。

### よくある質問（質問と、その返信）

質問：料金はいくらですか？
```
1ページのホームページ・LPで5,000円〜（税込）です。
公開後は月0円（自分で管理）から選べます。くわしくはこちら
https://hpworks.hp-web.workers.dev/service.html
```

質問：無料デモってなんですか？
```
お店に合わせたトップページのデモを、無料でおつくりしてスマホで見てもらうものです。
見てからお断りいただいても大丈夫です。
5分ほどの質問シートに答えていただくと、デモづくりをはじめます。
https://hpworks.hp-web.workers.dev/hearing.html
```

質問：遠くても頼めますか？
```
全国どこからでも大丈夫です！やりとりはDMやLINEで完結します。
```

質問：相談だけでもいいですか？
```
もちろんです。「うちの場合はいくらくらい？」からでも、気軽にメッセージをどうぞ。
```
